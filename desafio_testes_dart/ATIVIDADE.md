# Situação de Aprendizagem

Uma biblioteca escolar contratou uma equipe para desenvolver um pequeno sistema de empréstimos. O sistema foi entregue como “finalizado”, mas apresenta comportamento inconsistente. Alguns erros impedem a compilação; outros aparecem apenas após os primeiros defeitos serem corrigidos. Existem ainda testes defeituosos, mensagens enganosas e regras de negócio contraditórias.

A equipe deverá:

1. executar a análise estática;
2. registrar os primeiros erros encontrados;
3. corrigir somente um problema por vez;
4. executar novamente os testes;
5. identificar os novos defeitos revelados;
6. classificar cada defeito;
7. criar testes adicionais;
8. justificar alterações no código de produção e nos testes;
9. demonstrar o sistema funcionando;
10. explicar por que mensagens de “código correto” não substituem evidências.
