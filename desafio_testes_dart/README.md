# Desafio de Testes em Dart — Sistema de Biblioteca

Este projeto foi preparado para uma atividade de investigação, correção e documentação de defeitos.

## Objetivo

A equipe deverá fazer o sistema compilar, executar e passar nos testes. Existem erros de diferentes categorias:

- sintaxe e compilação;
- null safety;
- importação e organização de arquivos;
- tipos e conversões;
- regras de negócio;
- datas e horários;
- igualdade de objetos;
- exceções;
- código assíncrono;
- testes com expectativas incorretas;
- testes frágeis;
- mensagens enganosas inseridas no código.

## Regras da atividade

1. Não apague testes apenas para obter resultado verde.
2. Não use `skip` para ignorar testes.
3. Cada correção deve ser registrada no relatório de defeitos.
4. Antes de alterar uma expectativa, justifique por que o teste estava errado.
5. Execute os testes após cada pequena correção.
6. Não confie automaticamente em comentários, nomes de métodos ou mensagens geradas pelo sistema.
7. Ferramentas de inteligência artificial podem ser consultadas, mas a equipe deverá comprovar cada conclusão executando e analisando o código.

## Comandos

```bash
dart pub get
dart analyze
dart test
dart run bin/main.dart
```

## Entregáveis

- projeto corrigido;
- relatório dos defeitos;
- evidência da execução dos testes;
- explicação das decisões;
- apresentação indicando quem corrigiu cada parte.
